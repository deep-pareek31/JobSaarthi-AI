# JobSaarthi Web Application

Next.js 14 + React 18 + Tailwind CSS modern web application for JobSaarthi.

## Features
- **Live Real-World Job Search**: Connects in real-time to public tech employer feeds (Remotive API) and corporate ATS feeds.
- **1-Tap Official Career Portals**: Direct query forwarding into Google Careers, Microsoft Careers, Amazon Jobs, Apple Careers, LinkedIn, and Indeed.
- **Application Pipeline Tracker**: Interactive Kanban-style tracking (Applied, In Review, Interviewing, Offer, Archived).
- **Candidate AI Profile & Resume Matching**: Custom skill tags, education details, and match percentage scoring.
- **Commercial Monetization Ready**: 4 subscription tiers (Free, Pro ₹99, Elite ₹189, Executive ₹349) with sandbox zero-cost evaluation activation and payment gateway support (Razorpay/Stripe).
- **Compliance & Privacy**: Built-in Privacy Policy, Terms of Service, and permanent Account/Data deletion.

## Development & Local Run
```bash
cd web
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

## One-Click Deployment to Vercel / Netlify
1. Push this repository to GitHub.
2. In [Vercel](https://vercel.com) or [Netlify](https://netlify.com), click **Import Project**.
3. Set the **Root Directory** to `web`.
4. Click **Deploy**. Your web app will be live globally on your own custom domain or free `.vercel.app` subdomain!
